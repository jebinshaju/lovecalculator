# ❤️ Love Calculator

This is a simple web application for calculating the love percentage between two people. It's a fun project that utilizes deep learning techniques to estimate the compatibility between two individuals based on their names, the number of years they've known each other, and their story of how they met.

## Live Demo

Check out the live demo [here](https://jebinshaju.github.io/lovecalculator)!

## Features

- Calculates the love percentage between two individuals.
- Requires input of names, the number of years known, and a short story of how they met.
- Utilizes deep learning algorithms for calculation.
- Simple and intuitive user interface.

## Usage

To use the Love Calculator:

1. Clone this repository to your local machine.
2. Open the `index.html` file in your web browser.
3. Fill in your name, your crush's name, the number of years you've known each other, and a short story of how you met.
4. Click on the "Calculate" button to see the love percentage.
